# SkyVista

React + Vite project. Har component ki apni `.jsx` aur `.css` file hai (vanilla CSS, Tailwind nahi).

## Run
```
npm install
npm run dev
```

## Structure
- src/components  -> UI components (each with its own .css)
- src/context     -> ToastContext, AuthContext
- src/data        -> constants.js (destinations, reviews, etc.)
- src/index.css   -> global variables, reset, animations
